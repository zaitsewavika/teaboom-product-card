# Карточка товара Teaboom

Тестовое задание: адаптивная карточка товара «Ананасовый улун» в стилистике Teaboom.ru.

При выборе фасовки обновляются артикул, актуальная цена, цена без скидки и подпись веса. Цена со скидкой выделяется красным; при отсутствии скидки отображается только обычная цена. Кнопка «В корзину» демонстрационная, реальная корзина не подключена.

## Запуск

Откройте `index.html` в браузере или через Live Server. Установка зависимостей для просмотра не нужна: готовый CSS включён в проект.

## Работа с SCSS

Для сборки нужен Node.js с npm. Выполняйте команды из папки проекта:

```bash
npm install
npm run build:css
```

Автоматическая сборка при изменении SCSS:

```bash
npm run watch:css
```

Остановить наблюдение можно сочетанием `Ctrl + C`. После изменения SCSS сохраняйте обновлённый `assets/css/styles.css` в репозитории.

## Технологии и подходы

- HTML5, SCSS (Sass), JavaScript без фреймворков.
- Mobile first, CSS Grid и Flexbox, именование классов по БЭМ.
- Семантическая разметка, нативные радиокнопки, клавиатурный фокус и ARIA для скринридеров.
- Локальный Open Sans в WOFF2, изображения WebP и SVG.
- Prettier и EditorConfig для форматирования кода.

Изображения и информация о товаре взяты с Teaboom.ru. Лицензия Open Sans находится в `assets/fonts/OpenSans-OFL.txt`.
